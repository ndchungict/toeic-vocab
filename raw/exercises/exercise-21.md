## Bảng tổng hợp từ vựng

| Từ | Phiên âm (IPA) | Loại | Nghĩa | Collocation thường gặp | Ví dụ câu tiếng Anh |
|---|---|---|---|---|---|
| device | /dɪˈvaɪs/ | n | thiết bị | a mobile / smart device | Aria is a smart-home device. |
| install | /ɪnˈstɔːl/ | v | cài đặt, lắp đặt | install the software → **installation** | They installed the OS on each unit. |
| configure | /kənˈfɪɡə(r)/ | v | cấu hình | configure the settings | They configured it for Halston's network. |
| upgrade | /ˈʌpɡreɪd/ | v/n | nâng cấp | upgrade the system / firmware | They upgraded the firmware. |
| software / hardware | /ˈsɒftweə(r)/ · /ˈhɑːdweə(r)/ | n | phần mềm / phần cứng | ⚠️ cả hai **không đếm được** | The software runs on the new hardware. |
| database | /ˈdeɪtəbeɪs/ | n | cơ sở dữ liệu | update / back up the database | They built a customer database. |
| server | /ˈsɜːvə(r)/ | n | máy chủ | the server is down | A server cluster was set up near Halston. |
| network | /ˈnetwɜːk/ | n | mạng | the company network | They configured the internal network. |
| back up | /bæk ʌp/ | v | sao lưu | back up your files → **backup** (n) | Always back up before a change. |
| restore | /rɪˈstɔː(r)/ | v | khôi phục | restore the data | If it fails, restore the data. |
| troubleshoot | /ˈtrʌblʃuːt/ | v | khắc phục sự cố | troubleshoot the issue | They troubleshot the early build. |
| glitch | /ɡlɪtʃ/ | n | lỗi kỹ thuật nhỏ | a technical glitch | A glitch made the light blink. |
| crash | /kræʃ/ | v/n | treo, sập (hệ thống) | the system crashed | The app sometimes crashed. |
| compatible | /kəmˈpætəbl/ | adj | tương thích | compatible **with** sth | It wasn't compatible with some routers. |
| interface | /ˈɪntəfeɪs/ | n | giao diện | a user-friendly interface | He refined the interface. |
| functionality | /ˌfʌŋkʃəˈnæləti/ | n | chức năng | limited functionality | They trimmed extra functionality. |
| technician | /tekˈnɪʃn/ | n | kỹ thuật viên | call a technician | A technician joined the team. |
| help desk | /ˈhelp desk/ | n | bộ phận hỗ trợ kỹ thuật | contact the help desk | They set up a help desk. |

> ⚠️ **Bẫy hay gặp:** **software** & **hardware** là danh từ **KHÔNG đếm được** (không *-s*). **back up** (động từ, 2 chữ) → **backup** (danh từ, 1 chữ); **install** → **installation**. **compatible** luôn đi **with**. Phân biệt **glitch** (lỗi nhỏ) < **crash** (treo/sập cả hệ thống); **troubleshoot** = đi tìm & khắc phục sự cố. **interface** (giao diện) ≠ **functionality** (chức năng) ≠ *feature* (tính năng — Lesson 22). **upgrade** (nâng cấp lên bản tốt hơn) khác *update* (cập nhật). **technician** (người) vs **help desk** (bộ phận) — cùng mảng hỗ trợ kỹ thuật.

### Part 5 — Incomplete Sentences

**1.** Aria is a smart-home ______ that depends heavily on its software.
(A) glitch (B) device (C) server (D) interface

**2.** The team had to ______ the operating system on every prototype unit.
(A) restore (B) upgrade (C) troubleshoot (D) install

**3.** Engineers had to ______ the settings to match Halston's network.
(A) configure (B) crash (C) back up (D) install

**4.** They also had to ______ the firmware to the latest version.
(A) restore (B) troubleshoot (C) upgrade (D) configure

**5.** When the ______ went down, none of the devices could connect.
(A) interface (B) server (C) glitch (D) manual

**6.** John told Ben to always ______ the data before making any change.
(A) crash (B) configure (C) install (D) back up

**7.** If an update failed, they could ______ the data from the last backup.
(A) restore (B) upgrade (C) troubleshoot (D) install

**8.** The early build was buggy, so the team spent days trying to ______ it.
(A) configure (B) install (C) troubleshoot (D) back up

**9.** A minor ______ caused the status light to blink at the wrong time.
(A) server (B) glitch (C) network (D) interface

**10.** For no clear reason, the control app would occasionally ______.
(A) install (B) configure (C) upgrade (D) crash

**11.** The software was not ______ with some routers common in Halston.
(A) compatible (B) portable (C) durable (D) obsolete

**12.** He redesigned the ______ to make the app easier to use.
(A) database (B) server (C) interface (D) glitch

## Đáp án & giải thích

### Part 5
1. **B (device)** — "a smart-home device… depends on its software" = thiết bị. *glitch/server/interface* sai nghĩa.
2. **D (install)** — "install the operating system on every unit" = cài đặt. *restore/upgrade/troubleshoot* sai nghĩa.
3. **A (configure)** — "configure the settings to match the network" = cấu hình. *crash/back up/install* sai nghĩa.
4. **C (upgrade)** — "upgrade the firmware to the latest version" = nâng cấp. *restore/troubleshoot/configure* sai nghĩa.
5. **B (server)** — "when the server went down, no device could connect" = máy chủ. *interface/glitch/manual* sai nghĩa.
6. **D (back up)** — "always back up the data before any change" = sao lưu. *crash/configure/install* sai nghĩa.
7. **A (restore)** — "restore the data from the last backup" = khôi phục. *upgrade/troubleshoot/install* sai nghĩa.
8. **C (troubleshoot)** — "buggy build… trying to troubleshoot it" = khắc phục sự cố. *configure/install/back up* sai nghĩa.
9. **B (glitch)** — "a minor glitch… light blink at the wrong time" = lỗi kỹ thuật nhỏ. *server/network/interface* sai nghĩa.
10. **D (crash)** — "the control app would occasionally crash" = treo/sập. *install/configure/upgrade* sai nghĩa.
11. **A (compatible)** — "not compatible with some routers" = tương thích. ⚠️ đi với *with*. *portable/durable/obsolete* sai nghĩa.
12. **C (interface)** — "redesigned the interface to make the app easier to use" = giao diện. *database/server/glitch* sai nghĩa.

### Part 6
13. **C (database)** — "set up the customer database" = cơ sở dữ liệu. *interface/glitch/manual* sai nghĩa.
14. **A (network)** — "connect every store to the company network" = mạng. *technician/server/glitch* sai nghĩa.
15. **D (functionality)** — "test the app's core functionality on real devices" = chức năng. *hardware/voltage/interface* sai nghĩa.

18. **D (compatible)** — "Aria is compatible with most home routers" = tương thích. *portable/obsolete/durable* sai nghĩa.
